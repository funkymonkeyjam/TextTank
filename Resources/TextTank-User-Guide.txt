TextTank User Guide

Getting started
Open a local file with File → Open or create a blank tab with File → New. Use File → Save to choose a destination for a new document. A document with unsaved edits remains open when you cancel a close review. Help → Welcome to TextTank opens an editable tutorial.

Finding a command or file
Press Shift-Command-P to search commands. Read the scope shown beside an action before choosing it. Unavailable actions depend on the current document or comparison. Use Quick Open to search file names under the folders you selected for your workspace. Opening an already edited file returns you to its existing buffer.

Editing and searching
Use Command-F for the current document's Find bar. Use the controls there to move through matches and change the search options. Find and Replace offers additional search and replacement actions. Before changing many files, choose the search folder and review which results will be replaced.

Comparing versions
File → Compare with Saved Version compares the active file on disk with its editor contents. A comparison has its own window. Review its changes there and return to the original tab to continue editing. If a file changes outside TextTank, review the notice in its tab before choosing Reload.

Editor groups
View → Editor Layout lets you place groups side by side. Move to Group moves a tab. Open in Another Group shows the same document in both groups, with independent views and shared edits. Returning to Single Group brings the tabs together.

Automations and macros
The Automations menu lists saved workflows. Read the input and destination before running one. Clean up recipe list reads the current document and replaces its text. Macros can record supported editing commands for replay. Stop recording before saving a macro. Edit → Undo reverses a change in the active document.

Command review
The Run menu lists configured commands. On first use or after a configuration changes, inspect the executable, arguments and working directory. A shell-mode entry passes the displayed script to the shell. Cancel leaves the command unstarted.

Keeping your work
Save changes you intend to keep in their file. Recovery can offer unsaved drafts after an interruption. A recovered draft opens separately so you can decide where to save it. Compare the draft with the file before replacing either version.

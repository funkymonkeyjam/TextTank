TextTank User Guide

Getting started
The menu bar has nine menus. File opens, saves and re-encodes documents. Edit changes the text. Find searches and moves through it. View changes how it is shown. Compare, Tools, Window and Help hold comparisons, macros and automations, tabs, and these guides.

Open a local file with File → Open… or create a blank tab with File → New. Use File → Save to choose a destination for a new document. A document with unsaved edits remains open when you cancel a close review. Help → Welcome to TextTank opens an editable tutorial.

Finding a command or file
Press Shift-Command-P, or choose Help → Command Palette…, to search commands. Type the words of a command in any order, or the menu you remember it in. The best match for the name comes first. Each row shows the menu that holds the command and its keyboard shortcut, if it has one. Before you type, the five commands you ran from the palette most recently are listed first. Unavailable actions depend on the current document or comparison. Use File → Quick Open… (Shift-Command-O) to find a document by name: open documents are listed first, then recent files, then the files under the folders you selected for your workspace. Choosing an open document shows its tab; it is never opened a second time.

Workspace Browser
View → Workspace Browser shows a sidebar at the left of the window, beside your documents, and a checkmark in the menu while it is shown. Choose it again to hide the sidebar. The pop-up at the top switches between Open Documents, Folders and Recent Files. Add a folder with Add Folder…, or with File → Workspace → Add Folder to Workspace…. Choosing View → Workspace Browser moves the keyboard to the list: use the arrow keys to move, type the start of a name to jump to it, and press Return to open the selected file or select its tab. Press Escape to return to your text and leave the sidebar showing. Hiding the sidebar also returns the keyboard to your text, and neither changes your selection or scroll position. Drag the divider to make the sidebar wider or narrower. TextTank remembers its width and whether it was shown the next time you open the app. While the sidebar is shown the window cannot be made as narrow as usual, so the text always keeps its room.

Editing and searching
Use Find → Find… (Command-F) for the current document's Find bar. Use the controls there to move through matches and change the search options. Click the disclosure arrow at the start of the bar to show or hide its Replace row. Find → Go to Line… (Command-L) shows one field in the same place: type a line, or a line and column such as 12:4, then press Return to go there or Escape to stay where you were. Find → Find and Replace… offers additional search and replacement actions. The Find bar and the Find and Replace window share one Find text, one replacement and a list of your last ten of each: press Down Arrow in a field, or click the magnifying glass in the bar or the arrow at the end of a field in the window. A new launch starts in Normal mode with an empty Find field. In a very large document, Normal and Extended searches show their progress and can be cancelled; to use a regular expression there, select part of the document and choose Selection. Edit groups the commands that change text: Lines, Indentation and Whitespace, Convert Case, Comment, Selection, Delete, Line Endings, and Encode and Decode. View → Syntax Highlighting chooses the document's language. Before changing many files, choose the search folder and review which results will be replaced.

Comparing versions
Compare → Compare with Saved Version compares the active file on disk with its editor contents. A comparison has its own window. Review its changes there and return to the original tab to continue editing. If a file changes outside TextTank, review the notice in its tab before choosing Reload.

Each time you save a file, TextTank keeps a private copy of what it wrote, and the first time it saves over content it has not seen, a copy of what was there before. These earlier versions stay on this Mac in TextTank’s own support folder, never beside your file. TextTank keeps the last 20 versions of each file for up to 30 days, and at most 200 MB in all; the oldest are removed first, and a save larger than 32 MiB is not kept. Compare → Compare with Earlier Version… lists the versions of the active file by date and size. Choose one to compare it with the current text. The earlier version is read-only. To restore it, or part of it, choose Compare → Merge Changes → Select All Changes or Select Changes…, then Apply Selected Changes: the document changes in one Undo step, and the file changes only when you save. Compare → Clear Local History… deletes the kept versions of the active file, or of every file, after asking; it does not change your files and cannot be undone. Untitled documents and Save Copy keep no earlier versions.

Tabs
A tab shows the document’s name. When the document has unsaved edits, a dot takes the place of the tab’s close button; move the pointer over the tab and the dot becomes the close button again. Clicking either closes the tab and asks about unsaved edits as usual. A warning triangle on a tab means its file changed outside TextTank, and a pair of arrows means the document is selected for comparison. Hold the pointer over either symbol to read what it means. Hold it over the tab to see where the file is. Click a tab with the middle mouse button to close it. Double-click the empty part of the tab bar to create a new document. When a group has more tabs than fit, a chevron appears at the end of its tab bar; click it for a list of that group’s tabs and choose one to show it.
Moving the keyboard around the window
Window → Move Focus → Move Focus to Next Area (F6) moves the keyboard to the next part of the window: the Workspace Browser when it is shown, then each editor group's tabs, find bar, text and status row. Move Focus to Previous Area (Shift-F6) goes the other way. Option-Command-` and Shift-Option-Command-` do the same. In the tabs, the Left and Right Arrow keys move between tabs and Tab reaches a tab's close button; press Space or Return to choose. In the status row, the arrow keys or Tab move between the items and Space opens one. Escape returns to the text. Moving the keyboard never changes your selection, your place in the text or the tab that is showing.

Editor groups
View → Editor Groups → Editor Group Layout lets you place groups side by side. The Editor Layout button in the toolbar offers the same layouts. A group with no tabs shows New and Open buttons, the keys for New, Open, Quick Open and the Command Palette, and up to five recent files you can open with a click. Move to Group moves a tab. Show Tab in Another Group shows the same document in both groups, with independent views and shared edits. Returning to Single Group brings the tabs together.

Showing the text
View → Split Tab View shows two views of the tab's document side by side; choose it again, while it has a checkmark, to return to one. View → Show holds what is drawn with the text: Line Numbers, Whitespace, Line Endings, Indentation Guides, Current Line Highlight, Matching Braces and Change Bars. Each applies to every document and is remembered.

View → Show → Change Bars adds a narrow margin beside the text that marks the lines changed since the document was opened. A wide bar is a change you have not saved. A narrow bar at the left is a change that is saved. A hollow bar in the middle is a line you returned to its original text with Undo after saving. Undo and Redo move the bars with the text, and reverting or reopening a document clears them. A document you had already edited when you turned Change Bars on shows no bars until you revert or reopen it; your Undo history is never removed to start them. Very large documents, and comparisons, have no change bars.

View → Centered Text Column lays the text out as a column in the middle of the view, with equal margins either side; line numbers stay at the left edge. Set the column's width in characters in TextTank → Settings…, under Appearance. It does not change your document or Wrap Lines: with Wrap Lines on the text wraps at the column, and with it off a long line runs on as before. When the view is narrower than the column, the text uses the whole width.

Source, Preview and Both
View → Preview → Source / Preview / Both chooses what a tab shows. Source is the text you edit. Preview shows the document formatted, and Both places the two side by side with a divider you can drag. Markdown, HTML and SVG are shown as a page, CSV and TSV as a table, and JSON as a tree you can open and close. An SVG, CSV or TSV document needs its file extension, so save it first. The preview follows your unsaved text shortly after you stop typing; it never saves or changes the document. A page runs no scripts and loads nothing from the internet. It can use stylesheets and images in the document's own folder. A line above the preview says what was left out. A link you click opens in your browser. Table values appear exactly as written, and Copy copies the selected rows. When JSON is not valid, the line above the tree says where, and Go to Error places the caret there. Find and Go to Line show the source beside the preview. In Both, choose View → Preview → Both again to move the keyboard between the source and the preview. Documents larger than 8 MB have no preview.

View → Preview → Toggle Preview (Shift-Command-V) switches between Source and the preview: from Source it shows Preview or Both, whichever you chose last, and from either of those it returns to Source. You can also switch from the tab itself. A tab that shows Preview or Both carries an eye; click it to return to Source. Move the pointer over the tab of a document that has a preview and the eye appears; click it to show Both. Neither click selects the tab. Control-click any tab for Source, Preview and Both in its menu, which also work for a tab that is not in front. To have a kind of document open in Preview or Both every time, choose TextTank → Settings…, click Previews, pick the kind under Preview format and choose Open in. This applies to files you open from then on. Tabs that are already open, tabs reopened from your last session and untitled documents keep what they show.

In Both, the two sides scroll together for Markdown, CSV, TSV and JSON: scroll the source and the preview shows the matching heading, paragraph, row or value; scroll the preview and the source goes to the matching line. Scrolling never moves the caret or the selection. HTML and SVG are not followed. Editing above the place you are reading in a Markdown preview does not move it. View → Preview → Sync Scrolling in Both turns this off and on; it is the same setting as Sync scrolling in Both under Previews in Settings.

Automations and macros
Tools → Automations lists saved automations. Read the input and destination before running one. A new installation includes one automation, Add to Reminders, which asks you to choose a Reminders list and sends nothing until you choose Send. Add your own in Tools → Automations → Manage Automations…; the Welcome document walks through a first one. Tools → Macros can record supported editing commands for replay. Stop recording before saving a macro. Edit → Undo reverses a change in the active document.

Command review
Tools → Run Commands lists configured commands. On first use or after a configuration changes, inspect the executable, arguments and working directory. A shell-mode entry passes the displayed script to the shell. Cancel leaves the command unstarted.

Settings
TextTank → Settings… (Command-comma) has five panes: Editing, Appearance, Files, Previews and Shortcuts. Click a pane's button at the top of the window. A change applies as soon as you make it. To find a setting without knowing its pane, type in the search field (Command-F moves to it); settings from every pane that match are listed, and a word such as "theme" or "startup" also finds the setting it describes. Select Changed from default to list only the settings you have changed; Use Default beside one returns that setting to its default. Files has Reveal Settings File in Finder.

Shortcuts lists every command in the menu bar with its key. Search by a command's name, its menu or a key. To give a command a shortcut, select it and click the button that shows its key (or press Return), then press the keys: any combination of Command, Option, Control and Shift with a key, or a function key on its own. Escape keeps the current shortcut. A key that would type text, and a system shortcut such as Command-Q, is refused with the reason. If another command already has the key, TextTank names it and offers Replace or Cancel. Use Default returns the selected command to its default, Clear Shortcut leaves it without one, and Reset All Shortcuts… restores every default. Macro, automation and editor group keys are shown but are not changed here; an automation's shortcut is set in Tools → Automations → Manage Automations….

Keeping your work
Save changes you intend to keep in their file. When you quit, TextTank asks about each file that has unsaved edits: Save, Don’t Save or Cancel. It does not ask about untitled documents. Their unsaved text is kept, and at the next launch those tabs come back in the same order, group and pin state, with the same text, caret, language, encoding and line endings, still untitled and still marked edited. A status message says how many were restored. Undo history is not kept across a quit. Closing a single untitled tab still asks whether to save it. If TextTank cannot confirm that an untitled document’s text was stored, or the document is larger than 256 MiB, it asks about that document at quit as before; one quit keeps at most 256 untitled documents and 512 MiB of text, and asks about any beyond that.

After a crash or power loss the same happens for untitled documents: they reopen with the last text TextTank stored, which can be up to a few seconds old. For a file with unsaved edits TextTank offers a recovery copy instead. A recovery copy opens separately so you can decide where to save it. Compare the recovery copy with the file before replacing either version.

TextTank User Guide

Getting started
The menu bar has nine menus. File opens, saves and re-encodes documents. Edit changes the text. Find searches and moves through it. View changes how it is shown. Compare, Tools, Window and Help hold comparisons, macros and automations, tabs, and these guides.

Open a local file with File → Open… or create a blank tab with File → New. Use File → Save to choose a destination for a new document. A document with unsaved edits remains open when you cancel a close review. Help → Welcome to TextTank opens an editable tutorial.

Finding a command or file
Press Shift-Command-P, or choose Help → Command Palette…, to search commands. Type the words of a command in any order, or the menu you remember it in. Read the scope shown beside an action before choosing it. Unavailable actions depend on the current document or comparison. Use File → Quick Open… to search file names under the folders you selected for your workspace. Opening an already edited file returns you to its open tab.

Workspace Browser
View → Workspace Browser shows a sidebar at the left of the window, beside your documents, and a checkmark in the menu while it is shown. Choose it again to hide the sidebar. The pop-up at the top switches between Open Documents, Folders and Recent Files. Add a folder with Add Folder…, or with File → Workspace → Add Folder to Workspace…. Choosing View → Workspace Browser moves the keyboard to the list: use the arrow keys to move, type the start of a name to jump to it, and press Return to open the selected file or select its tab. Press Escape to return to your text and leave the sidebar showing. Hiding the sidebar also returns the keyboard to your text, and neither changes your selection or scroll position. Drag the divider to make the sidebar wider or narrower. TextTank remembers its width and whether it was shown the next time you open the app. While the sidebar is shown the window cannot be made as narrow as usual, so the text always keeps its room.

Editing and searching
Use Find → Find… (Command-F) for the current document's Find bar. Use the controls there to move through matches and change the search options. Find → Find and Replace… offers additional search and replacement actions. Edit groups the commands that change text: Lines, Indentation and Whitespace, Convert Case, Comment, Selection, Delete, Line Endings, and Encode and Decode. View → Syntax Highlighting chooses the document's language. Before changing many files, choose the search folder and review which results will be replaced.

Comparing versions
Compare → Compare with Saved Version compares the active file on disk with its editor contents. A comparison has its own window. Review its changes there and return to the original tab to continue editing. If a file changes outside TextTank, review the notice in its tab before choosing Reload.

Editor groups
View → Editor Groups → Editor Group Layout lets you place groups side by side. Move to Group moves a tab. Show Tab in Another Group shows the same document in both groups, with independent views and shared edits. Returning to Single Group brings the tabs together.

Source, Preview and Both
View → Source / Preview / Both chooses what a tab shows. Source is the text you edit. Preview shows the document formatted, and Both places the two side by side with a divider you can drag. Markdown, HTML and SVG are shown as a page, CSV and TSV as a table, and JSON as a tree you can open and close. An SVG, CSV or TSV document needs its file extension, so save it first. The preview follows your unsaved text shortly after you stop typing; it never saves or changes the document. A page runs no scripts and loads nothing from the internet. It can use stylesheets and images in the document's own folder. A line above the preview says what was left out. A link you click opens in your browser. Table values appear exactly as written, and Copy copies the selected rows. When JSON is not valid, the line above the tree says where, and Go to Error places the caret there. Find and Go to Line show the source beside the preview. In Both, choose View → Both again to move the keyboard between the source and the preview. Documents larger than 8 MB have no preview.

View → Toggle Preview (Shift-Command-V) switches between Source and the preview: from Source it shows Preview or Both, whichever you chose last, and from either of those it returns to Source. You can also switch from the tab itself. A tab that shows Preview or Both carries an eye; click it to return to Source. Move the pointer over the tab of a document that has a preview and the eye appears; click it to show Both. Neither click selects the tab. Control-click any tab for Source, Preview and Both in its menu, which also work for a tab that is not in front. To have a kind of document open in Preview or Both every time, choose TextTank → Settings…, pick the kind under Preview format and choose Open in. This applies to files you open from then on. Tabs that are already open, tabs reopened from your last session and untitled documents keep what they show.

Automations and macros
Tools → Automations lists saved automations. Read the input and destination before running one. A new installation includes one automation, Add to Reminders, which asks you to choose a Reminders list and sends nothing until you choose Send. Add your own in Tools → Automations → Manage Automations…; the Welcome document walks through a first one. Tools → Macros can record supported editing commands for replay. Stop recording before saving a macro. Edit → Undo reverses a change in the active document.

Command review
Tools → Run Commands lists configured commands. On first use or after a configuration changes, inspect the executable, arguments and working directory. A shell-mode entry passes the displayed script to the shell. Cancel leaves the command unstarted.

Keeping your work
Save changes you intend to keep in their file. After an interruption TextTank can offer recovery copies of unsaved text. A recovery copy opens separately so you can decide where to save it. Compare the recovery copy with the file before replacing either version.

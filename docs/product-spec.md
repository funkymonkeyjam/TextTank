# Product contract

Native Swift/AppKit, Objective-C++ bridge, Scintilla Cocoa and Lexilla. macOS 27.0 minimum. Independent application, GPL-3.0-or-later. All standard Notepad++ behaviors at reference 61246e5741fd7c59352f3feb5ccc7e33e4594d15 remain required, including bundled tools. No paid tier. Carbon Caret identity: carbon #15201F, paper #F4F6F0, citrus #C7F45B; light action #3A5B00. Native controls retain system fonts.

Automations have stable UUIDs, editable names, versioned typed steps and parameters, explicit inputs/outputs, shared trigger dispatch, editable preview/cancel and grouped editor Undo. Ordinary paste stays ordinary. Recorded macros are separate required functionality. Recipe cleanup must preserve quantities, fractions, duplicates and boundaries. EventKit requires explicit list selection and consent; uncertain external writes cannot be silently retried.

## Required behavior and evidence

The [capability matrix](parity/README.md) retains source requirements, Mac equivalents, aliases/parameters and focused evidence connections. Unassessed behavior remains required; inventory presence, menu wiring and assertion totals are never completion claims. User-named automations and recorded macros are implemented extensions to the editor, with remaining gaps stated in [REVIEW-ME](REVIEW-ME.md).

Every external action is explicitly invoked and reports its actual outcome; no import, open or restore runs code or sends document text. A text transformation captures then revalidates its document/revision/selection and is one Undo action. Editor Undo does not undo file or Reminders effects. Strict file encodings, atomic private recovery and unrecoverable-error preservation remain product requirements.

The workspace host uses one native window with a compact tab strip and one, two or four editor groups. Captured tab menus, transactional close, pin/reorder/multi-selection and Clone views preserve one Scintilla document and shared Undo. Closed-tab history retains live unsaved state within its bounded session lifetime; session/recovery storage stays separate. Explicit saved-layout restore and immutable DocumentTarget identity/revision/reload guards follow [tab-model](tab-model.md). The owner overflow rule preserves the active tab and announces a moved tab's position. Foundation adds the headless shared immutable snapshot/exact-change/bounded diff and single-use revision-safe apply layer specified in [review-model](review-model.md); D1 adds native read-only comparison for tabs, saved files, explicit clipboard text and selections, with exact captured text, side-by-side/unified views, bounded cancellable computation and explicit stale-source Refresh, as specified in [compare-model](compare-model.md). D2 adds explicit destination-bound selective merging and complete unified patch export through the existing Foundation applier, as specified in [merge-model](merge-model.md). Comparison renderers remain read-only. Patch import, filters, three-way merge and provider interfaces remain later capabilities. The settled workspace-window model, red-close-button behavior, toolbar rules and open distribution/menu decisions are in [DESIGN-STANDARDS](DESIGN-STANDARDS.md), which remains binding. A deployment target, configured CI image or successful local check does not certify an unobserved OS, architecture, GUI or accessibility task.

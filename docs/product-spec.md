# Product contract

Native Swift/AppKit, Objective-C++ bridge, Scintilla Cocoa and Lexilla. macOS 14 minimum. Independent application, GPL-3.0-or-later. All standard Notepad++ behaviors at reference 61246e5741fd7c59352f3feb5ccc7e33e4594d15 remain required, including bundled tools. No paid tier. Carbon Caret identity: carbon #15201F, paper #F4F6F0, citrus #C7F45B; light action #3A5B00. Native controls retain system fonts.

Automations have stable UUIDs, editable names, versioned typed steps and parameters, explicit inputs/outputs, shared trigger dispatch, editable preview/cancel and grouped editor Undo. Ordinary paste stays ordinary. Recorded macros are separate required functionality. Recipe cleanup must preserve quantities, fractions, duplicates and boundaries. EventKit requires explicit list selection and consent; uncertain external writes cannot be silently retried.

## Required behavior and evidence

The [capability matrix](parity/README.md) retains source requirements, Mac equivalents, aliases/parameters and focused evidence connections. Unassessed behavior remains required; inventory presence, menu wiring and assertion totals are never completion claims. User-named automations and recorded macros are implemented extensions to the editor, with remaining gaps stated in [REVIEW-ME](REVIEW-ME.md).

Every external action is explicitly invoked and reports its actual outcome; no import, open or restore runs code or sends document text. A text transformation captures then revalidates its document/revision/selection and is one Undo action. Editor Undo does not undo file or Reminders effects. Strict file encodings, atomic private recovery and unrecoverable-error preservation remain product requirements.

The Stage 0 workspace host uses one native window and one visible editor group; its Foundation tab model and codec-only layout state are specified in [tab-model](tab-model.md). Stage 1 adds captured tab menus, transactional bulk close, and session-only disk-backed reopen of the last 20 closed file tabs. Locate in Workspace is deferred because the lazy browser has no select-by-URL contract; Stage 2 adds per-tab pinning, in-group drag/keyboard reorder and transient multi-selection with captured Close/Pin counts. Pinned tabs are excluded from implicit bulk close; explicit selected close includes pins and retains transactional review. The active tab stays visible after a move; the moved tab's position is announced. Additional groups and saved layouts remain outside this stage. The settled workspace-window model, red-close-button behavior, toolbar rules and open distribution/menu decisions are in [DESIGN-STANDARDS](DESIGN-STANDARDS.md), which remains binding. A deployment target, configured CI image or successful local check does not certify an unobserved OS, architecture, GUI or accessibility task.
